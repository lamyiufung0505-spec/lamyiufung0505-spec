# Yiu Fung Lam (蓝耀锋)

Computer Science undergraduate at Beijing Jiaotong University (2023 - 2027).
I build small, working systems around Chinese NLP, retrieval and LLM agents.

## Repositories

- **[ai-travel-planner](https://github.com/lamyiufung0505-spec/ai-travel-planner)** - WeChat mini program + FastAPI backend: a three-agent DeepSeek pipeline (Researcher -> Planner -> Critic) turns a short brief into a day-by-day itinerary with cited sources.
- **[ai-browser-agent](https://github.com/lamyiufung0505-spec/ai-browser-agent)** - LLM agent driving a real browser through a Playwright tool loop, with DeepSeek ReAct prompting.
- **[ai-rag-qa](https://github.com/lamyiufung0505-spec/ai-rag-qa)** - local document Q&A: on-device embeddings (fastembed) so files never leave the machine; DeepSeek for generation.
- **[HMM-CWS](https://github.com/lamyiufung0505-spec/HMM-CWS)** - Chinese word segmentation with a hand-implemented bigram HMM (BMES tagging, Viterbi decoding, Add-1 smoothing), plus a CRF POS-tagging baseline.

*Other projects: CLIP + OCR image retrieval; Arduino sensor labs.*
